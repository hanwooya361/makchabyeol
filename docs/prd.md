# 막차별 PRD (개발용 사본)

원본: [막차별 PRD (Claude 문서)](https://claude.ai/artifact/NuwnggDV3AbYANdDQU2imD) · 2026-11-07 리뷰 반영본. 원본이 바뀌면 이 파일도 함께 고쳐요.

## 개요

막차별은 막차를 기다리는 밤, 걱정 하나를 별에 맡기고 가는 정류장이에요. 1인 개발로 4주 안에 MVP를 출시해요.

- **세계관**: 밤 버스 정류장. 버스는 오지 않아도 괜찮은 곳
- **핵심 의식**: 걱정 한 줄을 쓰면 별이 되어 하늘에 떠오름
- **재방문 장치**: 교통카드를 "삑" 찍으면 그날의 버텼다 도장이 됨
- **원칙**: 로그인 없음, 최소 수집, 위기 사용자 대응 필수, 월 고정비 1만원 이내

## 문제 정의

| 페르소나 | 상황 | 기분 | 필요한 것 |
| --- | --- | --- | --- |
| 서연 (27, 마케터) | 평일 23시, 야근 끝나고 버스 정류장. 내일 발표가 걱정됨 | 지침, 허탈함 | 버스 오기 전 3분 안에 끝나는 짧은 위로 |
| 준호 (24, 취업 준비) | 새벽 2시, 불합격 메일을 받고 잠이 안 옴 | 불안, 나만 뒤처지는 것 같음 | 누구에게도 보이지 않고 털어놓을 곳 |

두 사람 모두 상담이나 조언을 원하지 않아요. 가입하거나 길게 쓰는 순간 떠나요.

## 핵심 경험

**정류장에 앉아 카드를 찍고, 걱정 한 줄을 별로 띄운 뒤, 오늘 밤 혼자가 아니었다는 걸 보고 떠난다.**

1. 0~5초: 어두운 정류장과 가로등 하나. 전광판에 "막차까지 ∞분"
2. 5~10초: 단말기에 카드를 탭하면 "삑." "오늘도 여기까지 왔네요."
3. 10~15초: 화면이 위로 올라가 밤하늘. "버스 오기 전에, 걱정 하나 맡기고 갈래요?"
4. 15~25초: 한 줄 입력(최대 100자) → 별이 되어 떠오름
5. 25~30초: "오늘 밤 별 128개가 떴어요. 혼자 기다리는 거 아니에요."

카드 찍기와 별 띄우기는 둘 다 건너뛸 수 있어요.

## 사용자 스토리와 수용 기준

걱정 원문은 서버에 저장하지 않는 것이 기본안이에요. 서버에는 별 기록(익명 방문자 ID, 위치, 색, 시각)만 남아요.

### M1. 정류장 메인 + 카드 찍기

- Given 첫 방문자, When 3초 안에, Then 로그인 없이 정류장과 단말기가 보인다
- Given 오늘 밤 아직 안 찍은 방문자, When 단말기를 탭하면, Then "삑" 피드백과 함께 오늘 밤 날짜가 기기에 기록되고, 서버에는 익명 방문자 ID와 날짜만 남는다
- Given 오늘 밤 이미 찍은 방문자, When 다시 탭하면, Then 도장은 늘지 않고 "오늘은 이미 찍었어요"가 나온다

### M2. 별에 걱정 맡기기

- Given 입력창이 열려 있을 때, When 1~100자를 쓰고 "맡기기"를 누르면, Then 3초 이내의 애니메이션 뒤 별이 하늘에 고정된다
- Given 빈 입력, When 버튼을 누르면, Then 버튼이 비활성이라 아무 일도 없다
- Given 별이 저장됐을 때, When 서버 요청을 확인하면, Then 걱정 원문은 전송되지 않는다
- Given prefers-reduced-motion, When 별을 띄우면, Then 움직임 대신 페이드만 쓴다

### M3. 오늘 밤 별 개수

- Given 하늘 화면, When 화면이 뜨면, Then 오늘 밤(한국 시간 정오에 하루가 바뀌는 밤 날짜 기준) 별 개수와 다른 별들의 빛이 보인다
- Given 화면을 열어 둔 채, When 30초가 지나면, Then 개수가 갱신된다
- Given 별이 5개 미만, When 화면이 뜨면, Then 숫자 대신 "오늘 밤 첫 별들 중 하나예요"

### M4. 위기 사용자 안내

- Given 입력에 위기 키워드, When "맡기기"를 누르면, Then 별은 그대로 뜨고 그 뒤 다정한 문구와 109(24시간) 안내 카드가 뜨며, 전화 버튼은 tel:109
- Given 안내 카드, When 닫기를 누르면, Then 바로 닫히고 같은 세션에서 다시 뜨지 않는다
- Given 어느 화면이든, When 푸터를 보면, Then "도움받을 곳" 링크가 보인다
- Given 안내 카드, When 전화가 어려우면, Then 24시간 SNS 상담 마들랜 링크로도 연결할 수 있다
- Given 안내 카드가 떴을 때, When 서버 기록을 보면, Then 원문 없이 "안내 카드 노출 1회"만 익명으로 집계된다

### 후원 링크 (Should, 붙일 때의 기준)

- 별을 띄우기 전에는 보이지 않는다
- 별을 띄운 뒤 작은 텍스트 링크 하나만, 팝업 없음
- 위기 안내 카드가 떴던 세션에서는 숨긴다

## 리스크

| 리스크 | 심각도 | 대응 |
| --- | --- | --- |
| 위기 사용자를 놓침 | 높음 | 키워드 감지 + 푸터 상시 링크. 오탐이 나도 카드 하나 뜨는 게 전부. 키워드 목록은 출시 전 별도 검토 |
| 위기 빈도를 운영자가 모름 | 높음 | 원문 없이 안내 카드 노출 횟수만 익명 집계 |
| 정류장 그림 작업이 일정을 잡아먹음 | 중간 | CSS·SVG로 단순하게. 1주차에 화면 하나 먼저 완성 |
| 별 도배로 개수 조작·DB 폭주 | 중간 | 방문자 ID·IP당 rate limit. 초과분은 화면에만 띄우고 저장 안 함 |
| 익명 ID 저장을 고지하지 않음 | 중간 | 개인정보 처리방침에 명시 |
| 저작권 | 중간 | 상업적 사용 가능한 무료 소스만, docs/credits.md에 기록 |
| 위로의 상업화로 보임 | 중간 | 후원은 의식 뒤 텍스트 링크 하나, 위기 세션에선 숨김 |
| 초기 방문자가 적어 하늘이 텅 비어 보임 | 중간 | 배경 별을 깔고, 개수가 적으면 문구로 표시 |
| 스팸·광고 | 낮음 | 남에게 보이는 텍스트가 없음 |
| 비용 폭증 | 낮음 | 무료 한도 스택, 폴링 30초 + 캐시 |
