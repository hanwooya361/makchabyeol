# 막차별 PRD (개발용 사본)

원본: [막차별 PRD (Claude 문서)](https://claude.ai/artifact/NuwnggDV3AbYANdDQU2imD) · 2026-11-07 리뷰 반영본. 원본이 바뀌면 이 파일도 함께 고쳐요.

## 개요

막차별은 버스를 기다리는 밤, 걱정 하나를 별에 맡기고 집에 가는 정류장이에요. 1인 개발이에요. 의식(M1~M5)은 완성됐고, 아래 "공개 출시 전" 기능을 **로컬에서** 모두 만든 뒤 AWS로 한 번에 배포해 공개 출시해요([출시 기준](#출시-기준)).

- **세계관**: 밤 버스 정류장. 버스는 자주 오고, 놓쳐도 괜찮은 곳. 목적지는 "집"
- **핵심 의식**: 걱정 한 줄을 쓰면 별이 되어 하늘에 떠오름
- **마무리 장치**: 5분마다 오는 버스에 타서 교통카드를 "삑" 찍으면 오늘 하루를 마무리하고 집에 도착함. 탄 밤의 별이 이어져 나만의 별자리(B4)
- **원칙**: 로그인 없이 시작(가입은 다른 기기에서 기록을 잇고 싶은 사람만), 강요 없음, 최소 수집, 위기 사용자 대응 필수, 월 고정비 1만원 이내

## 문제 정의

| 페르소나 | 상황 | 기분 | 필요한 것 |
| --- | --- | --- | --- |

두 사람 모두 상담이나 조언을 원하지 않아요. 가입하거나 길게 쓰는 순간 떠나요.

## 핵심 경험

**정류장에서 걱정 한 줄을 별로 띄우고, 오늘 밤 혼자가 아니었다는 걸 본 뒤, 버스를 타고 집에 간다.**

1. 0~5초: 어두운 정류장과 가로등 하나. 전광판에 "다음 버스 N분". 내 캐릭터가 정류장에 서 있음
2. 5~15초: 걸어 다니거나 "하늘 보기". "버스 오기 전에, 걱정 하나 맡기고 갈래요?"
3. 15~25초: 한 줄 입력(최대 100자) → 별이 되어 떠오름. "오늘 밤 별 128개가 떴어요. 혼자 기다리는 거 아니에요."
4. 버스가 오면(5분마다, 1분 정차) 버스에 들어가 카드를 "삑" → 버스가 출발하고 "집에 도착" 화면

순서는 별 → 버스 → 카드. 별을 안 띄웠으면 버스 문 앞에서 한 번 물어보고, "오늘은 맡길 게 없어요"를 고르면 글 없이 희미한 별 하나만 띄우고 탐. 버스를 놓쳐도 불이익은 없음("다음 버스 타도 괜찮아요").

## 사용자 스토리와 수용 기준

걱정 원문은 서버에 저장하지 않는 것이 기본안이에요. 서버에는 별 기록(익명 방문자 ID, 위치, 색, 시각)만 남아요.

### M1. 버스 타고 집으로 (카드 찍기 = 탑승)

- Given 첫 방문자, When 3초 안에, Then 로그인 없이 정류장과 "다음 버스 N분" 전광판이 보인다
- Given 버스가 오는 시각(기기 시계, 매시 0·5·10…분), When 누구든 볼 때, Then 같은 버스가 들어와 약 1분 서 있다가 출발한다
- Given 버스 문이 열려 있고 캐릭터가 버스 안에 있을 때, When 카드 찍기를 누르면, Then "삑"과 함께 오늘 밤 날짜가 기기에 기록되고 서버에는 익명 ID와 날짜만 남고, 버스가 출발해 "집에 도착" 화면이 나온다. 그 전에는 카드 버튼이 꺼져 있다
- Given 문이 열려 있을 때, When "버스 타기" 버튼을 누르면, Then 캐릭터가 알아서 버스에 들어간다(2D에서는 바로 탑승)
- Given 별을 아직 안 띄웠을 때, When 버스 문 앞에 오면, Then "걱정 하나 맡기고 갈래요?"를 묻고, "오늘은 맡길 게 없어요"를 고르면 글 없이 희미한 별 하나만 띄우고 탈 수 있다
- Given 버스를 놓쳤을 때, Then 아무 불이익 없이 "다음 버스 타도 괜찮아요"만 보인다. 카드를 안 찍고 버스 안에 있었으면 문 앞 인도로 내려 주고 탑승 처리하지 않는다
- Given 오늘 밤 이미 탄 방문자, When 다시 타면, Then 기록은 늘지 않고 "오늘은 이미 집에 다녀왔어요. 그래도 와 줘서 고마워요."가 나온다

### M2. 별에 걱정 맡기기

- Given 입력창이 열려 있을 때, When 1~100자를 쓰고 "맡기기"를 누르면, Then 3초 이내의 애니메이션 뒤 별이 하늘에 고정된다
- Given 빈 입력, When 버튼을 누르면, Then 버튼이 비활성이라 아무 일도 없다
- Given 별이 저장됐을 때, When 서버 요청을 확인하면, Then 걱정 원문은 전송되지 않는다
- Given prefers-reduced-motion, When 별을 띄우면, Then 움직임 대신 페이드만 쓴다

### M3. 오늘 밤 별 개수

- Given 하늘 화면, When 화면이 뜨면, Then 오늘 밤(한국 시간 정오에 하루가 바뀌는 밤 날짜 기준) 별 개수와 다른 별들의 빛이 보인다
- Given 화면을 열어 둔 채, When 30초가 지나면, Then 개수가 갱신된다
- Given 별이 5개 미만, When 화면이 뜨면, Then 숫자 대신 "오늘 밤 첫 별들 중 하나예요"

### M4. 위기 사용자 안내

- Given 입력에 위기 키워드, When "맡기기"를 누르면, Then 별은 그대로 뜨고 그 뒤 다정한 문구와 109(24시간) 안내 카드가 뜨며, 전화 버튼은 tel:109
- Given 안내 카드, When 닫기를 누르면, Then 바로 닫히고 같은 세션에서 다시 뜨지 않는다
- Given 어느 화면이든, When 푸터를 보면, Then "도움받을 곳" 링크가 보인다
- Given 안내 카드, When 전화가 어려우면, Then 24시간 SNS 상담 마들랜 링크로도 연결할 수 있다
- Given 안내 카드가 떴을 때, When 서버 기록을 보면, Then 원문 없이 "안내 카드 노출 1회"만 익명으로 집계된다

### M5. 3D 정류장·밤하늘

- Given 중간급 안드로이드 폰, When 정류장과 하늘을 오가고 별 300개가 뜬 하늘을 볼 때, Then 30fps 이상을 유지한다
- Given Fast 4G, When 처음 들어오면, Then 3초 안에 첫 화면(2D)이 보이고 5초 안에 3D 장면으로 바뀐다
- Given WebGL이 없거나 모션 줄이기가 켜져 있을 때, When 들어오면, Then 2D 대체 화면에서 모든 의식(M1~M4)이 그대로 동작한다(버스는 전광판 시간 + "버스 타기" 버튼)
- Given 정류장, When PC에서 마우스 오른쪽 버튼으로 끌거나 폰에서 한 손가락으로 끌면, Then 카메라가 캐릭터 둘레를 돈다. 땅 밑으로는 내려가지 않는다
- Given 정류장, When 짧게 탭하면(끈 거리 8px 미만), Then 캐릭터가 그 자리로 걸어간다
- Given PC, When WASD나 방향키를 누르고 있으면, Then 카메라가 보는 쪽을 기준으로 계속 걷는다. 입력칸에 쓰는 중에는 걷지 않는다
- Given 카메라를 위로 많이 올렸을 때, Then 하늘 장면으로 넘어가지 않고 "하늘 보기" 버튼만 살짝 강조된다

### 후원 링크 (Should, 붙일 때의 기준)

- 별을 띄우기 전에는 보이지 않는다
- 별을 띄운 뒤 작은 텍스트 링크 하나만, 팝업 없음
- 위기 안내 카드가 떴던 세션에서는 숨긴다

### 공개 출시 전 기능

새 연출은 3D에만 넣어요. 2D 대체 화면은 동결이라 의식이 같게 흘러가는 데 필요한 것(HTML 버튼·문구)만 받아요. 새 연출이 들어가도 M5의 성능 기준(30fps, 초기 JS 450KB)은 그대로예요.

#### A1. 버스 창밖

- Given 버스 안에서, When 카드를 찍으면, Then 버스가 약 10초 달리고 창밖으로 가로등이 지나간 뒤 집 도착 화면이 나온다
- Given 달리는 중, When "건너뛰기"를 누르면(키보드 포함), Then 바로 집 도착 화면이 나온다. 연출 중 포커스는 "건너뛰기"에 있다
- Given 모션 줄이기 또는 2D, When 카드를 찍으면, Then 연출 없이 바로 집 도착 화면이 나온다
- Given 연출 중, When 서버가 잠들어 있어도, Then 연출과 집 도착은 서버 응답을 기다리지 않는다

#### A2. 실제 시간대 하늘

- Given 기기 시계, When 정류장에 들어오면, Then 시간대에 맞는 하늘 색(해 질 녘 → 밤 → 새벽)이 보이고 바뀔 때는 천천히 섞인다. 서버 요청은 없다
- Given 어느 시간대든, When 글자를 보면, Then 배경 대비 4.5:1 이상이다(시간대마다 실측)
- Given 낮 시간(대략 9~17시), When 들어오면, Then 해 질 녘 색에 머문다. 밝은 낮 하늘은 만들지 않는다(세계관이 밤 정류장)

#### A3. 환경음

- Given 첫 방문, When 들어오면, Then 소리는 꺼져 있다
- Given 소리 켜기 버튼(HTML, 키보드·스크린리더), When 켜면, Then 가로등 지지직·먼 차 소리가 작게 반복되고 다음 방문에도 켜진 상태가 기억된다(기기에만)
- Given 날씨가 비(C7), When 소리가 켜져 있으면, Then 비 소리가 더해진다
- Given 위기 안내 카드가 떠 있을 때, Then 소리는 그대로 두되 카드 위에 소리 조작이 겹치지 않는다
- Given 소리 파일, When 출처를 보면, Then docs/credits.md에 출처·라이선스가 있다(상업적 사용 가능한 것만)

#### B4. 별자리

- Given 버스를 탄 밤이 1개 이상, When 하늘에서 "내 별자리"를 열면, Then 이번 달 탄 밤의 내 별이 날짜 순으로 선으로 이어져 보인다. 1개면 별 하나만
- Given 별자리, Then "N일 남았어요"·"완성까지" 같은 목표나 빠진 날 표시는 없다
- Given 가입 안 한 방문자, When 같은 기기로 오면, Then 별자리가 보인다(익명 ID 기준). 다른 기기에서 보려면 가입(G)
- Given 90일이 지난 기록, Then 별자리에서도 사라진다(보존 기간과 같음)
- Given 스크린리더, When 별자리를 열면, Then "이번 달 별 N개가 이어져 있어요"를 읽는다

#### B5. 아바타 꾸미기

- Given 꾸미기 패널(HTML), When 옷 색·목도리·모자 중에서 고르면, Then 내 캐릭터가 바로 바뀌고 기기에 기억된다. 가입했으면 계정에도 저장된다
- Given 선택지, Then 정해진 목록뿐이다. 글자·사진·직접 그리기 없음, 유료 아이템 없음
- Given 같이 있기(T26), When 다른 사람이 나를 보면, Then 내가 고른 모습으로 보인다

#### B6. 탑승 기록

- Given 이번 달 버스를 탄 밤이 N번, When 집 도착 화면이나 별자리에서 보면, Then "이번 달 집에 간 밤 N번"만 보인다
- Given 0번, Then 숫자 문구는 보이지 않는다
- Given 어떤 경우에도, Then 빠진 날·연속 일수·지난달과 비교는 말하지 않는다

#### G. 선택 가입

- Given 가입 안 한 방문자, When 들어오면, Then 지금과 똑같이 의식하고 가입 권유 팝업은 없다. 입구는 푸터 "기록 잇기" 하나
- Given 가입 화면, When 아이디·비밀번호를 쓰고 "만 14세 이상이에요"를 체크하면, Then 계정이 생기고 복구 코드가 딱 한 번 보인다. "저장했어요"를 눌러야 닫히고, 이 기기의 별·탑승 기록이 계정으로 옮겨진다
- Given 14세 확인을 안 했으면, Then 가입 버튼이 꺼져 있다
- Given 다른 기기, When 로그인하면, Then 그 기기에서도 별자리·탑승 기록·꾸미기가 이어지고, 그 기기의 익명 기록도 계정으로 옮겨진다
- Given 비밀번호를 연속 5번 틀리면, Then 15분 잠긴다. 메시지는 아이디가 있든 없든 "아이디나 비밀번호가 맞지 않아요"로 같다
- Given 복구 코드와 새 비밀번호, When 재설정하면, Then 비밀번호가 바뀌고 새 복구 코드가 나오며 다른 기기의 로그인은 모두 끊긴다
- Given 비밀번호와 복구 코드를 둘 다 잃었으면, Then 계정은 되찾을 수 없다. 가입 화면에서 미리 알려 준다
- Given 탈퇴, When 비밀번호를 다시 넣으면, Then 계정과 연결된 별·탑승 기록이 바로 지워지고 이 기기는 새 익명 ID로 시작한다
- Given 로그아웃, Then 이 기기는 새 익명 ID로 시작한다(공용 기기에서 다음 사람 기록이 내 계정에 붙지 않게)
- Given 로그인한 상태로 별을 띄우면, Then 요청에 걱정 원문이 없다
- Given 같이 있기에서 말풍선을 쓰려면, Then 계정이 있어야 한다. 가입 없이도 보기·걷기·반짝·고양이·캔은 된다
- Given 서로 다른 계정 3명이 24시간 안에 한 계정을 신고하면, Then 그 계정은 24시간 말풍선을 못 쓰고(다시 접속하거나 다른 기기로 와도 그대로), 30일 안에 다시 걸리면 7일. 신고에 말풍선 내용은 남지 않는다

#### C7. 실제 날씨

- Given 서울 날씨가 비·눈·흐림·맑음, When 정류장을 보면, Then 3D에 빗줄기·눈·옅은 구름·맑은 하늘로 보인다. 2D와 모션 줄이기는 그림 없이 그대로
- Given 날씨, Then 사용자 위치는 묻지도 받지도 않는다(서울 고정). 화면 어디에도 "서울"이라고 단정하지 않는다("오늘 밤 비가 와요" 정도)
- Given 서버는 30~60분마다 기상청 값을 새로 받아 둔다, When 기상청 API가 실패하거나 키가 없으면, Then "맑은 밤"으로 보이고 화면은 기다리지 않는다
- Given 비가 와도, Then 3D 성능 기준(30fps)을 지킨다

#### C8. 관리자 대시보드

- Given 관리자 권한 계정, When 관리자 페이지에 들어가면, Then 일별 별 수·탑승 수·위기 안내 노출 수·방문 수(T22.6)와 서버 상태(가동, DB 연결, 날씨 캐시 시각)가 보인다
- Given 관리자 페이지, Then 개별 방문자·계정의 기록, 아이디, 익명 ID는 어디에도 보이지 않는다(집계만)
- Given 일반 계정이나 로그인 안 한 사람, When 관리자 주소에 들어가면, Then 403이고 페이지 내용은 받지 않는다
- Given 관리자 권한, Then 가입으로는 얻을 수 없고 운영자가 DB에서 직접 부여한다

#### C9. 오늘 밤의 한 줄

- Given 관리자가 문장(40자 이하)과 보일 밤 날짜를 정해 저장하면, When 그 밤에 정류장을 보면, Then 전광판에 "다음 버스 N분"과 번갈아 가끔 흐른다(몇 분에 한 번, 버스 정보를 가리지 않음)
- Given 문장에 "마지막·떠나다·끝내다·그만"이나 위기 키워드가 있으면, When 저장하면, Then 저장되지 않고 이유가 보인다
- Given 위기 안내 카드가 떠 있을 때, Then 한 줄은 흐르지 않는다
- Given 스크린리더, Then 흐르는 한 줄을 읽으라고 끼어들지 않는다(aria-live 없음, 전광판 안 글자로만)

#### C10. 운영 알림

- Given 서버 500 에러, When 생기면, Then 디스코드에 "서버 에러 N회(지난 10분)"가 온다. 같은 알림은 10분에 한 번까지
- Given 위기 안내 노출이 1시간에 기준치 이상, When 넘으면, Then "위기 안내 N회(지난 1시간)"가 온다
- Given 어떤 알림이든, Then 숫자와 시각만 있다. 익명 ID·IP·아이디·입력 내용은 없다
- Given 웹훅 주소가 비어 있으면, Then 알림 없이 서비스는 그대로 돈다

#### 방문 기록 (T22.6)

- Given 앱을 열면, When 응답을 기다리지 않고, Then 익명 ID와 밤 날짜만 한 번 기록된다(같은 밤 중복은 늘지 않음). 90일 뒤 삭제

#### D11. 정류장 고양이 · D12. 자판기 캔커피

- Given 정류장, When 고양이 옆으로 걸어가 누르면, Then 쓰다듬는 짧은 동작이 나온다. 고양이는 도망가거나 무시하지 않는다
- Given 자판기, When 누르면, Then 캔커피 하나가 나와 캐릭터가 손에 들고 기다린다. 돈·개수 제한·보상 없음
- Given 키보드·스크린리더, When HTML 버튼("고양이 쓰다듬기", "캔커피 뽑기")을 누르면, Then 캐릭터가 알아서 걸어가 같은 동작을 한다(T22.5 "버스 타기"와 같은 방식)
- Given 같이 있기, When 다른 사람이 보면, Then 내가 캔을 들고 있거나 고양이를 쓰다듬는 모습이 보인다

#### D13. 같이 버스 타기

- Given 같은 버스(같은 도착 시각)에 탄 사람들, When 버스 안에 있으면, Then 서로의 아바타가 버스 안 자리에 앉아 보인다. 정류장 정원(20명)과 같은 방 사람끼리만
- Given 누군가 카드를 찍으면, Then 그 사람 화면은 바로 출발하고(T22.5), 다른 사람 화면에서는 그 아바타가 자리에서 옅어져 사라진다
- Given 기기 시계가 서로 달라도, Then 서버 시각으로 맞춰 같은 버스를 본다
- Given "안 보기"한 사람, Then 버스 안에서도 보이지 않는다

#### D14. 반짝 보내기

- Given 지금 같은 정류장에 있는 사람의 아바타나 그 사람의 오늘 별, When 누르면(또는 HTML 버튼), Then 글 없는 반짝 하나가 그 사람 화면에 잠깐 보인다
- Given 반짝, Then 보낸 사람은 받는 사람에게 알려지지 않고 서버에 저장되지 않는다
- Given 같은 사람에게 1분에 1개, 전체 10초에 1개를 넘기면, Then 보내지지 않는다
- Given 받는 사람이 나를 "안 보기"했으면, Then 반짝은 가지 않고 나에게도 그 사실을 알리지 않는다

## 출시 기준

**공개 출시 조건**: 위 "출시 전" 기능 전부(A1~A3, B4~B6, G, C7~C10, D11~D14) + 같이 있기(T25~T28) + 방문 기록(T22.6)이 로컬(PostgreSQL, T24)에서 끝나고 하나씩 확인된 상태.

**공개 출시 전 점검(T45)**

- 3D 성능 기준(M5)을 새 연출(창밖·날씨·고양이·같이 있기 20명)까지 켠 상태에서 다시 잼
- 위기 키워드·해치는 말 목록 검토
- 개인정보 처리방침 최종본(계정·꾸미기·방문 기록·같이 있기 항목) 법률 검토
- 부하 테스트: 정류장 여러 개 × 20명 + 별·카드 요청, 서버 메모리 512MB 안에서
- AWS 구성·월 비용 결정(월 1만원 원칙과 비교)

**공개 출시(T46)**: 운영자가 AWS에 직접 배포하고, 공개 전에 실환경 점검(콘솔 에러 0, 위기 카드, 서버 재시작 뒤 로그인 유지)과 부하 테스트를 한 번 더 해요.

## 하지 않을 것

- 가입 요구·가입 권유 팝업, 가입해야만 되는 의식 (가입 없이 모든 기능이 이 기기에서 됨)
- 이메일·전화번호·실명 받기, 비밀번호 찾기 메일, 소셜 로그인 (복구는 복구 코드로만)
- 공개 일기, 채팅 기록·지난 대화·댓글·DM (말풍선은 몇 초 뒤 사라지고 저장하지 않음)
- 닉네임 직접 입력 (자동 생성만)
- 상담·조언·AI 상담 답장
- 푸시 알림·이메일 알림
- 연속 방문 기록, 랭킹 (압박 문구만이 아니라 기능 자체를 만들지 않음. 탑승 기록은 "이번 달 N번" 숫자만)
- 사용자 위치 받기 (날씨는 서울 고정)
- 꾸미기 유료 아이템·뽑기
- 문구에 "마지막", "떠나다", "끝내다", "그만" 같은 말 (위기 사용자에게 다르게 읽힐 수 있음). 목적지는 "집"
- 가상 조이스틱 (탭 이동 + 한 손가락 끌어서 카메라 돌리기로 충분)
- 앱 출시 (모바일 웹만)
- 외부 3D 모델·공들인 일러스트 (3D는 로우폴리 기본 도형만)
- 2D 장면 추가 개발 (대체 화면으로 동결, 버그 수정만)
- 다른 사람 별에 마우스를 올리거나 눌러서 닉네임·내용 보기. 별은 빛만 보임(글은 서버에 없음). 누르면 반짝(D14)만 갈 수 있음

| 2D 출시 없이 3D를 기다리느라 출시가 밀림 | 중간 | T17을 2~3일로 끊고 결과로 판단. 미달이면 원인을 고쳐 다시 재고, 그래도 안 되면 출시 방식을 다시 정함 |
| 채팅으로 위기 사용자가 공격받음 ("죽어버려" 같은 말) | 높음 | 채팅은 안전장치와 같은 티켓에서만 출시(T27). 해치는 말 서버 차단, 안 보기·신고 누적 시 말 막기, 기록이 남지 않는 말풍선. 혼자 걷는 3D를 먼저 출시해 채팅 없이도 서비스가 성립하게 |
| 별 도배로 개수 조작·DB 폭주 | 중간 | 방문자 ID·IP당 rate limit. 초과분은 화면에만 띄우고 저장 안 함 |
| 익명 ID 저장을 고지하지 않음 | 중간 | 개인정보 처리방침에 명시 |
| 저작권 | 중간 | 상업적 사용 가능한 무료 소스만, docs/credits.md에 기록 |
| 위로의 상업화로 보임 | 중간 | 후원은 의식 뒤 텍스트 링크 하나, 위기 세션에선 숨김 |
| 초기 방문자가 적어 하늘이 텅 비어 보임 | 중간 | 배경 별을 깔고, 개수가 적으면 문구로 표시 |
| 스팸·광고 | 낮음 | 남에게 보이는 텍스트가 없음 |
| 비용 폭증 | 낮음 | 무료 한도 스택, 폴링 30초 + 캐시 |
| 기능이 많아 공개 출시가 계속 밀림 | 높음 | 티켓별 예상 기간을 tech-design 7장에 두고, 두 배 넘게 밀리면 범위를 다시 정함 |
| 로컬에서만 만들어 배포 때 한꺼번에 문제가 터짐 | 높음 | T24부터 로컬 DB를 운영과 같은 PostgreSQL로, 테스트도 PostgreSQL(Testcontainers). "같은 주소" 조건을 처음부터 지킴(로컬 Vite 프록시). T46은 공개 전에 실환경 점검 단계를 둠. 막히면 남겨 둔 Render·Cloudflare 설정으로 대체 |
| AWS 비용이 월 1만원을 넘음 | 중간 | T45에서 구성별 월 비용을 계산해 결정. 무료 크레딧 기간 값으로 판단하지 않음 |
| 비밀번호 무차별 대입·유출 | 높음 | BCrypt 저장, 계정별 5회 실패 시 15분 잠금 + IP 제한, 아이디 존재 여부를 알려 주지 않는 같은 실패 메시지 |
| 복구 코드를 잃어 계정을 못 찾음 | 중간 | 가입 때 "되찾을 수 없다"를 미리 알림. 계정을 잃어도 익명으로 의식은 그대로 됨 |
| 아이디에 실명·연락처를 씀 | 낮음 | 입력칸 안내("실명이나 연락처는 쓰지 마세요"), 다른 사람에게 아이디는 보이지 않음(닉네임만) |
| 운영자 한 줄이 위기 사용자에게 상처가 됨 | 중간 | 저장할 때 금지어·위기 키워드 검사, 위기 안내 카드가 떠 있을 땐 흐르지 않음 |
| 관리자 계정 탈취 | 높음 | 권한은 DB에서만 부여, 관리자 주소 접근 제한은 배포 때 추가(T45에서 결정), 집계만 보이게 해 탈취돼도 개인 기록은 없음 |
| 기상청 API 장애·키 만료 | 낮음 | 캐시 + 실패 시 "맑은 밤". 운영 알림(C10)으로 실패만 알림 |
| 새 연출로 3D가 무거워짐 | 중간 | 티켓마다 `?debug`로 fps 확인, 공개 전 T45에서 전부 켜고 재측정. 미달 효과는 저사양에서 끔 |
